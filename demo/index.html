一勺糖 · 可玩原型

《欢闹厨房》玩法流程设计 v2.0 的浏览器垂直切片。
经营是主体，剧情由经营长出来。

三个动词

  • 递出去：按序点食材 → 提交
  • 抽开手：雇人 / 升设备 → 少点几下
  • 练回去：练习 → 熟练度 → 完美率

色彩板

焦糖橘 #E8A05C蜜桃粉 #F3BFC0 糖霜白 #FFF7EA莓果红 #D9534F 奶油杏 #F5E4C9焙茶棕 #5A3B2E

糖霜白只用于显形 / 选中 / 完美，日常 UI 不占用。

怎么玩

  • 点一张顾客卡选中
  • 按配方顺序点食材
  • 点「提交给顾客」出餐
  • 打烊后雇人 / 升设备 / 练一道

顶栏 ☰ 可打开「设计对照」，逐条查看本原型实现的机制与调档值。

第 1 天

这一版实现了什么

  • P1 接单经营（主体）
  • P2 练习 → 熟练度 M
  • P4 / P5 雇人 · 升设备（只减负）
  • P6 打烊账本（持续 sink）
  • P7 段位评定 / 页显形
  • P8 剧情由 T1–T5 触发
  • V1 干扰 · V2 无配方 · V4 自由炉
  • 3-3 剥离：自动化归零
  • 5-2/3/4 入队 → A 70%

刻意不做

  • 装备加完美率（违反 P3）
  • 扣金币 / 掉熟练度（违反 P4）
  • 托管整局（违反 P5）
  • 售卖配方 / 页数 / 熟练度

所有数值均为 demo 调档值，非最终平衡数值；正式数值见《数值调优表》并需 playtest 验证。
