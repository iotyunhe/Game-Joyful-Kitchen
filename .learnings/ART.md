## 风格定名
**「糖霜团子 / Sugar Dumpling」** = 软描边 + 圆润剪影 + 奶油暖色 + 哑光粉质的 2D 手绘可爱风。设计分辨率 1080×1920 竖屏（假设 A1，待确认）。

## 红线（违反即返工）
1. **零锐角、零纯黑描边、零硬阴影**。谐星反派的出糗必须落成笑点，不是事故。
2. **糖霜白 L97 独占**：日常 UI 不得占用，否则 G3 显形仪式失效。
3. **顾苦斗篷是墨绿 `#3E5545` + 蜜桃粉流苏，不是纯黑**。设定写「黑斗篷」，风格做减重；保留「窗帘改的」喜剧来源。这是唯一一处风格对设定的反向修正，已显式记录，**不得改回纯黑，也不得偷偷改设定文档**。
4. **漏雨屋顶一直漏**：S1 / S2 底图必须画水痕，任何批次不得「修好」。
5. **S8 是 S2 同一张桌子的延长**，不是独立对立的店；S6 在 5-4 撤摊。
6. **七人同框单出一张 `img_ending_group_v1`**，不靠七张立绘拼贴；数满 7 个头，不得有人缺席或留白。
7. **状态必须颜色 + 形状双区分**：扣书期置灰要叠封条图形，不能只降透明度。
8. 图片里**不放文字**（字体渲染），不放水印 / 签名 / 真实品牌 / 受保护 IP。

## 实跑发现（写进流程，后续批次必须遵守）
1. 纯色底约束不稳定：同批两张底色是 `#B09088` / `#F038B0`，**都不是 `#FF00FF`** → 逐张 `palette` 取色再抠。
2. 平台会在右下角加「AI生成 / WORKBUDDY」水印，提示词 `no watermark` 无效 → 后处理清除 + 每张目视复核。
3. 全局颜色 `keyout` 会误抠头发与围裙浅色 → 用**边缘连通抠图**（flood fill from border, tol 35）。
4. `check` 的「残留透明边」与「8–10% 安全边距」冲突 → 保留刻意留白并逐条说明，**禁止拉伸变形**；等比缩放与 8% 安全边距按规格执行。
5. `check` 会把不透明的 `_src.png` 判不合规 → src 存 `source/`，校验只跑 `final/`。
6. **场景类必须换专用技术段**：满幅不透明场景与「品红底 / 10% 安全边距 / 单一抠图主体」三句全冲突 → 已定义 `SCENE TECHNICAL v1`（替换三句 + 补满幅构图约束），`STYLE BLOCK v1` 一字未动；角色 / 道具 / UI 批次仍用原 `TECHNICAL v1`，两套并存。见 `art/欢闹厨房-常驻场景提示词包.md` §1.2。
7. **场景水印不能置透明**：满幅图把右下角挖成透明会缺一块画面 → 提示词把该区预留为平坦色块，后处理从正上方复制等大色块 + 12px 羽化回填；`generated/batch02_scenes/process_scenes.py` 可复现。
8. ImageGen 请求 `1080x1920` 实出 `1072×1920` → 等比缩放 + 中心裁切，**禁止拉伸补 8px**；`check` 报「尺寸非 2 的幂」属 `standalone` 全屏场景例外（清单 §1.3），逐条说明即可，不改尺寸。
9. **模型会往物件上写字**：S1 首版罐子出现 `sugar` / `flour` 英文标签 → 四条 SUBJECT 逐项点名「COMPLETELY BLANK」后重出通过，首版留 `_deprecated`；S2 账本、S3 招牌、S4 书页同步加强。红线「图里不放文字」必须写成可执行约束，只写 `no text` 不够。

## 放量方案（已定，第 2 批按此执行）
STYLE BLOCK v1 与 TECHNICAL v1 均不升版、不改动。TECHNICAL 的「纯 `#FF00FF` 底」作为生成目标保留；实出底色偏差由后处理链路兜住（逐张 `palette` 取色 + 边缘连通抠图）。理由：升版会使已冻结的 7 个提示词全部失效，而底色偏差本就能在后处理确定性解决。直接输出透明底的方案不采用，该方案需重画双版本链路并升 TECHNICAL v2。

## 迭代纪律
`_v1 → _v2`，旧版改名 `_deprecated` 保留不删；只改指定部分，不顺手改配色或线宽；连续两轮无实质修改意见即冻结。改锚点前先写明推翻哪几批资产。
