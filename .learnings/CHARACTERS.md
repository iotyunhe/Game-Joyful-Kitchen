# CHARACTERS ·《欢闹厨房》角色状态表

> 续写前必读。记录弧光进度与"当前可知信息"，防止已退场角色提前回归、身份提前暴露。

## 麦小满（主角 · 18 岁）
- 身份：面包房送货工 →「一勺糖」甜品店老板。
- 性格：手笨、心软、乐天、对「好吃」有野兽般直觉。口头禅「再来一炉就好！」
- 弱点：不会拒绝人，把别人的需要排在自己前面（沈如意背叛的情绪根）。
- 成长阶梯：手笨 → 手感 → 功夫 → 心意 → 无配方 → 放下。
- 状态：序章捡书；终章学全 101 页、受封「点心之神」但把匾挂在门后。
- 注意：全作唯一一次没说「再来一炉就好」是第三章 3-5。

## 糖老书（书灵 · 引导者）
- 形象：泛黄书页里浮出的皱脸，糖丝眼镜，说两句就打瞌睡。
- 真相：初代「点心之神」的一缕念头，第 101 页是他当年没写出的一页。**终章 6-4 才可揭底**。
- 关键动作：第三章 3-9 被扣走前撕下第 101 页一角塞进主角围裙。
- 状态（v1.1）：终章 6-6 书合上变成普通旧菜谱，**但没有散去**——第二天自己翻回柜台，嘟囔「神位我不要，这炉我得看着」，此后当店里的菜单本继续挑刺。**不得再写「书灵散去 / 功成身退」。**

## 雷千层（挑战者 · 22 岁）★ 谐星化 · 5-2 入队
- 千层酥世家「雷记」第七代。冷面、毒舌、称量到 0.1 克的强迫症。
- 动机：表层「技术即真理」；深层雷记被「点心之神」传说压三代，祖父临终念「差一炉」，他要终结神话。
- 底线：绝对公平，从不使阴招，输了当场认，替对手捡托盘。
- **谐星标签 · 冷面反差萌**：随身小秤连客人的笑声都要「记个数值」；天天说「我只是路过」却风雨无阻准点挑刺、准点吃完两块；偷偷收藏主角每一炉失败品并按焦度编号归档，被豆豆翻出来时耳根通红。
- **招牌翻车**：1024 层被顾苦的鸽子撞翻，坚持一片片捡回重数到天黑；发表「我不信神」必被糖老书一句「那你天天来干嘛」噎住。
- 三次交锋：第二章初战碾压 → 第二章再战平局 → 第五章 5-2 终战认输、交出雷记秘传并**当场入队**。
- 额外高光：第四章 4-5 主动上门替主角作证。
- **入队后**：技法总顾问；「雷记」改成「一勺糖·雷记分店」；依旧每天挑刺，挑完顺手洗碗；终章第 412 天还在说「我只是路过」。
- **不得让他提前示好**（第四章作证是唯一例外）；笑点必须来自反差，不得削弱实力。

## 顾苦（捣乱者 · 自称「苦味博士」）★ 谐星化 · 5-3 入队
- 黑斗篷是拿家里窗帘改的（下摆留流苏），登场必发表宣言，戏剧化、浮夸、总把自己坑了；被拆穿会小声补「……下次不会了」，然后下次照样。
- 动机：童年差两文钱被甜品店赶走 → 认定「甜是哄人的，苦才是真的」；其实只想让当年那个小孩被谁递一块什么。**童年细节直到第五章 5-3 才由他自己说出口。**
- 六种捣乱手法：糖罐换盐、温度计调乱、胡椒烟雾弹、雇鸽子占座、伪装评论家打一星、改门牌。
- **谐星标签 · 正经地不正经**：一本《作战记录簿》把捣乱编号成「苦味作战第 07 号」，写计划、画示意图、盖自制印章，然后每次都翻车；宣言念到一半总被鸽子 / 门铃 / 豆豆打断。
- **招牌翻车**：踩自己撒的糖粉滑倒、被自己雇的鸽子啄、斗篷勾门把、被自己烟雾弹熏哭、伪装评论家忘了摘「苦味博士」袖章、换盐后自己先偷吃一勺灌三杯水。
- 弧光：第一章登场 → 第三章 3-6 默默放下一袋没动手脚的糖就跑 → 第四章 4-3 被主角顺手救一次 → 第五章 5-3 被「苦甜交织」化解并**当场入队**（「这不是投降，是……深入内部观察」）。
- **入队后**：自封「首席试味官兼防捣乱演练总指挥」；鸽子收编为「咕咕外送队」；把六种捣乱手法编成「防捣乱演练」教材给新人上课，讲得极其骄傲；与沈如意组成「挑刺二人组」。
- 注意：他的捣乱必须真的造成麻烦，否则「战」这关不成立；但落点永远是笑，不是恨。

## 沈如意（背叛者 · 20 岁）★ 谐星化 · 5-4 入队
- 开张第一天应聘的搭档，管账跑堂，温柔利落，笑起来像店里的灯；别扭起来会一本正经地做很笨的事。
- 三层动机（v1.1 减重）：① 评审世家之女，家族拿弟弟的**甜点学徒名额**做筹码要拓印（弟弟自己跑来偷吃被豆豆抓包，与豆豆入职形成镜像笑点）；② 曾是菜谱候选继承者被刷掉，想证明「没有那本书我也能被看见」；③ 真的喜欢这家店，也真的委屈。
- 背叛（轻量化但不消失）：第三章 3-2 紧张得手抖，拓印三页还按了三个糖霜指印、把「海盐焦糖」拓成「海盐焦…」；评审会借题发挥摘星封炉扣书 → 3-3 账本留一行「对不住」。
- **谐星标签 · 最拙劣的伪装**：出走后没走远，在街对面摆「代记账」小摊，大口罩 + 墨镜 + 遮阳帽自以为天衣无缝——全街坊都认得她，周伯每天特地去照顾生意，豆豆常来报告「如意姐姐又把算盘拿反了」。
- 名台词：「你每次都说'再来一炉就好'……可你从来没问过我累不累。」（第五章说出时，顾苦在旁举手「我累」，全场笑场，气就化开）
- 弧光：第二章钩子（叠纸）→ 第三章背叛出走 → 第四章 4-4 暗中补原料单（**不露面**）→ 第五章 5-4 回来「我只替你站完最后一炉」→ **被豆豆一句「你抽屉还留着呢，算盘我也没借给别人」当场留下，正式归队**。
- **入队后**：复任掌柜，账本重新摊回柜台；终章 6-7 当着全员写下「今天不累。」。
- **红线（v1.1 修订）**：动机可被理解，行为不被原谅，但**别扭要可爱、伤害要轻**——不痛哭跪求、不写苦情身世、不让人真的恨她。**大团圆铁律：她必须归队，且归队当章就留在店里；不得再写「和解但不归队」「交账本就走」。**

## 周伯（见证者）
- 每天买最便宜一块桂花糕、从不说话的老邮差。
- 真实身份：退休的**初代糖勺评审**，因当年一次误判退隐。**第四章 4-7 才可亮明**。
- 关键：第一章 1-7 说全章唯一一句「……再来一块」；第二章 2-6 把「好吃」票投给主角；第三章 3-7 主动问「明天……还开吗」；第四章 4-6 因「没有配方的桂花糕」（亡妻的味道）落泪；第五章投关键一票；沈如意摆摊期间每天去照顾一次生意（喜剧细节）。
- 注意：前四章不得让他多话。

## 豆豆（试吃员）
- 街坊小孩。第一章翻窗偷吃被抓包 → 试吃员 → 第四章能帮手 → 终章独立看炉、挂新牌「今日营业 · 排名不重要」。
- **关键推手**：第五章 5-4 用一句「你抽屉还留着呢，算盘我也没借给别人」把沈如意留下，是全员团圆的关键一环；不得删改或换人。
