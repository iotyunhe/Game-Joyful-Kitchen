# GAMEPLAY ·《欢闹厨房》玩法设定圣经

> 续写关卡脚本 / 对话脚本 / 关卡文案前必读。任何玩法设定以本文件与 `output/欢闹厨房_玩法流程设计.md` 为准，不得擅改。
> 基于《主线故事大纲》v1.1 大团圆版。剧情设定另见 STORY_BIBLE / CHARACTERS / LOCATIONS / PLOT_POINTS / ERRORS。

## Fun Hypothesis（不可动摇）
把一炉「做砸了」的点心，靠反复练、忽然懂、临场稳住，变成一页会长糖霜插图的菜谱；而每翻过一页，店里就多一个人坐到同一张桌子上。
两个动词：**烤出来**（操作爽点）、**留下来**（养成爽点）。不服务其中任一者的系统，删掉。

## Design Pillars（用来否决需求）
| # | 支柱 | 否决示例 |
|---|---|---|
| P1 | 每一页都得自己烤出来 | 金币买菜谱页 → 违反「显形 ≠ 学会」与不可作弊 |
| P2 | 失败永远有笑声兜底 | 干扰事件造成真实进度损失且无喜剧落点 |
| P3 | 队伍长度就是进度条 | 队友只出现在剧情、不进操作系统 |
| P4 | 排名是解锁器，不是分数墙 | 评定失败要重刷三天日常 |

## 玩法清单：8 种常规 + 4 种规则态
| ID | 玩法 | 一句话 |
|---|---|---|
| P1 | 制作 · 练习关（练） | 无限重试不计分，攒手感；连焦三炉是教学不是惩罚 |
| P2 | 剧情关（悟） | 一次二选一「做给谁吃」，无失败态，选错只换台词 |
| P3 | 挑战关（战） | 限时 + 干扰下完整出餐，失败退回练习关不丢已学页 |
| P4 | 接单经营 | 多桌并行排序，客人等走只丢本单收入 |
| P5 | 装扮与器具升级 | 花钱买「看得见的变强」；**漏雨屋顶不可修** |
| P6 | 经营结算 | 读账本做次日备料；3-3 后结算按钮少一个 |
| P7 | 糖勺榜段位评定 | 升段＝看下一页，不设分数墙 |
| P8 | 队伍岗位派遣 | 入队即解锁；加成在挑战关需封顶 |
| V1 | 干扰事件池 | 顾苦六种手法，真造成麻烦但必带自食其果落点；5-3 后转演练教材 |
| V2 | 无配方模式 | 第四章，S4 置灰、已学菜逐道重铸 |
| V3 | 回想关卡 | 第 100 页重做玩家失败过的菜，三队友各守一炉 |
| V4 | 自由炉 | 终章关闭排名 / 金币 / 计时 / 评分，全作唯一不产出数值的一炉 |

## 三层核心循环
- **Moment-to-moment（0–30s）**：接单 → 选料/操作 → 火候判定（听声）→ 出餐 → 糖霜插图 + 吐槽气泡。失败 → 面团糊脸动画 + 材料成本价返还。
- **Session loop（5–10 min）**：开门 G1 → 2–3 波订单 → 中段干扰 G2 → 三重磨炼一关 → 结算 → 显形 G3 → 关门。本局不达标不扣已有页数，只顺延。
- **Long-term（8–12h）**：升段 → 新页显形（只给题目）→ 练/悟/战 → 页学成 → 新场景 + 新队友 → 五阶 → 百页回想 → 第 101 页。

**七幕 session 分配 [PLACEHOLDER]**：序章 1 / 一章 4 / 二章 5 / 三章 3 / 四章 6 / 五章 5 / 终章 1 = 25。

## 内容量切割（必须遵守）
101 页 ≠ 303 个关卡。按剧情权重分三层：**招牌菜 24 道**（完整三段式，绑定剧情节点）/ **常驻菜 76 道**（练 1 + 战 1，「悟」并入已有对话）/ **回想菜动态**（玩家失败过的，第 100 页一次性重做，不新增菜式）。关卡单元总量 224 [PLACEHOLDER]。**第 101 页不是菜**，不进关卡池、不产出数值。

## 剧情穿插：三个插入口 + 四条咬合规则
| 插入口 | 位置 | 形态 | 铁律 |
|---|---|---|---|
| G1 开门钩子 | session 开始、接单前 | 2–4 句对话 + 明确目标，≤20s，可跳过 | — |
| G2 关中气泡 | 制作 / 挑战关进行中 | 单句短气泡，≤2s，自动滚 | **绝不弹全屏对话框**（读字会糊锅，是反馈通道问题） |
| G3 关门落点 | 结算后、退出前 | 显形仪式 / 章末钩子 / 入场动画，≤40s | — |

- **R1** 每个剧情节点必须有「触发条件 + 场景 + 玩法 + 产出」四件套，写不出来就删或并入 G3。
- **R2** 冲突角色只在自己负责的磨炼里出现：雷千层→练（P1/P3）、顾苦→战（V1）、沈如意→悟（P2/P6）；入队后统一转 P8。
- **R3** 入队即解锁且当场可操作：5-2→S8、5-3→S9、5-4→S2 结算强化，同一次 session 内就能点开新按钮。
- **R4** 章末钩子＝下一次开门提示（1-7 显三页、2-7 叠纸、4-8 最后 13 页、5-7 第 101 页空白）。

## 关键设定解释（防穿帮）
- 第四章末「已显形 87 页」与「书被扣」不矛盾：扣书期**只显形题目、不学会**；批量显形给的是待办清单，三重磨炼仍在归还后逐页进行。不得改成「第四章直接学会 47 页」。
- 第三章「队伍变短」是玩法事件，不只是台词：S4 置灰、岗位清空、装扮加成停用、结算按钮少一个。
- V1 在 5-3 后从敌对机制原地转成教学机制（防捣乱演练），同一事件池两遍用法，零新增资源。

## 经济红线
- Sources：出餐收入 / 评定奖励 / 外送订单 / 回头客小费 / 剧情奖励（雷记秘传、补回的原料单）。
- Sinks：原料采购 / 器具升级 / 装扮 / 岗位派遣 / 干扰重做成本 / **鸽子饲料与外送队维护（5-3 后持续 sink）** / **手感值溢出转失败品收藏册**。
- 最大通胀风险＝装扮是一次性 sink。S9 维护费必须在 5-3 后立刻接入。
- **不卖配方、不卖页数、不卖「跳过三重磨炼」道具**。商业化若与「不可作弊」冲突，改商业化，不改铁律。

## Playtest 失败信号（验收单）
A 序章重试 5 次仍不懂「听声」→ 先查反馈通道，别改机制｜B 第三章退出率上升 → 查低谷长度，别删低谷｜C 第五章金币溢出 → 查 S9 维护费，别加装扮｜D 入队后没点新按钮 → 查 R3，别加过场｜E 玩家讨厌/轻视反派 → 查是否靠削弱实力取笑，别删麻烦、别加苦情｜F 终章有人缺席或出现「会不会回来」→ 查 6-2 七人同框，别留白。
