## Fun Hypothesis（不可动摇）
手忙脚乱地把一份点心递到快要不耐烦的客人面前，偶尔端出一炉「完美」的；赚来的钱让店里越来越不需要自己动手，而省下的时间又能回去把某一道练到炉火纯青。
三个动词：**递出去**（操作爽点）、**抽开手**（减负爽点）、**练回去**（养成爽点）。不服务其中任一者的系统，删掉。

## 剧情铁律的玩法层重解释（STORY_BIBLE 原文未改）
显形仍由段位解锁、只给这一页的菜谱（题目到手，手上没功夫也只出普通）；**首次成功做出＝页学成并长糖霜插图**。练＝练习关提升熟练度 M；悟＝剧情关由经营触发器驱动在 G1/G3 播放；战＝经营中的高压时段；不可作弊新增禁售熟练度 / 完美率 / 自动化跳过；第 100 页回想＝重做失败过或低 M 的菜补足 M。

## UI 一屏纪律（2026-11-16 用户定稿，所有后续 UI 必守）
- **一屏放全**：营业页所有需要操作的内容（顾客卡、配方、食材按钮、撤销 / 提交、底栏）必须在同一屏内显示完毕，不出现纵向滚动条，玩家不拉条。
- **食材台固定 5 格**：正常菜 3–4 味 + V1 干扰最高 5 味，统一补到 5 格；跨天、跨菜、有无干扰都保持同一排，不许出现「第一天 3 个、第三天 5 个」的排版跳变。
- **勾选纪律**：打钩只表示玩家已点且点够该食材的所需次数；补位格所需次数为 0，开局与点齐时都不打钩，绝不允许「配方 3 步、5 格全勾」。
- **不占屏的冗余信息一律删**：食材台标题「后厨食材台」去掉，步骤数并入配方行；其余装饰性标题同理。
- **公式与开发编号不对玩家可见**：`[PLACEHOLDER]`、`playtest`、P1–P8 / V1–V4 / T1–T5 / R5–R6 编号、完美率 / 收益公式、系数与持续 sink 等一律从玩家界面移除；需要核对设计口径时用 `?dev=1` 打开开发者视图。玩家文案只说看得见的结果，不说后台模型。
- **序章视觉小说式排版（2026-11-17 用户定稿，取代旧「堆叠文字框」）**：① 布局为「上方整幅剧情背景图（占屏约 2/3）+ 底部单一统一对话框」，旁白与对白都在同一个对话框里逐句播放，**禁止回到多个圆角文字框堆叠**。② 8 幕各配专属背景（`ASSET_PRO.proBg0..7`，按文本对应：糖勺榜街景 / 天降旧书 / 书里老头 / 四条规矩 / 冒烟烤炉 / 听糖灶台 / 糖霜显形 / 旧仓库招牌），复用 STYLE BLOCK v1 + SCENE TECHNICAL v1；人物形象 `charMai`（麦小满）、`charBook`（糖老书）用 TECHNICAL v1 品红底抠透明，人物发言时立绘从对话框上方探出，旁白不显示立绘。③ 逐字打字机保留：一次一字（34ms）+ 标点停顿，打字中按钮「快进 ›」补全当前句，打完后「下一句 →」/「继续 →」推进，「跳过开场」随时跳过；对话框右下有点状句进度。④ 序章页锁一屏（stage.fit），立绘/背景不出屏，玩家界面无开发编号。

## 三层核心循环
- **Moment-to-moment（0–30s）**：顾客进门（订单卡 + 耐心条）→ 按序点击食材（3–6 步）→ 提交给该顾客 → 品质判定 → 耐心系数结算 → 金币 + 评价。客人等走 → 本单收益 0、记流失，不扣金币 / M。
- **Session loop（5–10 min）**：开门 G1 → 备料 → 营业 N 波 → 中段一次干扰 / 评定 / 高压 → 打烊结算（扣原料、工资、维护）→ 投资决策（雇人升设备 / 买练习原料）→ 练习 1–2 道 → G3 显形仪式 → 关门。
- **Long-term（8–12h）**：升段 → 显形 → 学成 → 练 M → 完美率 ↑ → 单笔收益 ↑ → 雇人升设备 → 自动化率 ↑ → 吞吐 ↑ → 升段。

**长期张力（不假装可调和）**：练习不产金币却占打烊后时间与原料；全投自动化则完美率原地踏步，只练不雇人则接不完客人。两条投资必须交替推进。

## 四条核心机制
**模型 A 熟练度 → 完美率 → 收益**：每道菜独立 M ∈ [0,100]，来源为练习（主要）/ 经营出餐（微量）/ 回想补足。**金币不可购买 M**。每次提交判一次品质 [PLACEHOLDER]，**只有两档，不设失败档**：
- 完美 `clamp(0.05+0.0055M, 0.05, 0.60)` → Q ×1.5 → 好评（覆盖耐心）
- 普通 `1 − p_perfect` → Q ×1.0 → 按耐心档
- 保底：连续 N 单未出完美后第 N+1 单强制完美 [PLACEHOLDER]

**模型 B 耐心 → 收益 / 评价 / 离场**：提交瞬间锁存 `p = 剩余耐心 / P0`；`T(p) = 0.5 + 0.5p` [PLACEHOLDER]；普通品质评价阶梯 p ≥ 0.6 好评 / 0.3–0.6 中评 / < 0.3 差评 [PLACEHOLDER]；**p = 0 顾客离场，收益 0，记流失客数，不额外差评、不扣金币、不掉 M**。

**单笔收益 = 基础价 B × 品质系数 Q × 耐心系数 T(p)**。
**结算顺序唯一**：判品质（完美 / 普通）→ 锁存 p → 算 Q×T(p) → 判评价档（完美覆盖好评、普通按 p 阶梯）→ 发金币与好评率。
**投料工序全局固定**：乳脂与液体基底 → 蛋与油脂 → 粉类成型 → 熬糖调味 → 点缀装饰；配方、食材台、V1 干扰插入后共用同一条顺序，不随机排列。
**负反馈唯一来源**：顾客耐心归零离场。倒计时内按序提交必出货，普通保底 Q=1.0；熟练度只决定上行波动，不制造下行惩罚。
**完美 × 耐心默认方案 A**：完美强制好评，但耐心系数照常生效（不免疫 T(p)）。方案 B / C 见设计文档 3.3，待商讨 Q1。

**评价回收口**：当日好评率 → 次日客流基数；流失客数 → 当日评价上限；**累计好评率 → 糖勺榜评定「谁在吃」项（4-7 起进入公式）**；差评只压好评率不扣金币。

## 减负与自动化（P3）
员工与设备**会影响**：手动点击步数 / 单位时间吞吐 / 并行顾客上限 / 出餐等待 / 结算备料接管。
**不会影响**：熟练度 M / 完美率 / 品质判定 / 单笔基础价 / 耐心初值 / 段位评定结果。吞吐提高间接提高单位时间金币，不是给每单偷偷加钱。

- 员工 4 类岗位（备料 / 烤制 / 上菜 / 收银），一次性雇佣 + **每 session 工资（持续 sink）**；发薪不足 → 「今天请假」，不裁员不扣进度。只接管已学会菜品，新菜首做 / 异常订单 / 干扰强制手动。
- 设备 1–5 级，每级减 1 个手动步骤或缩短出餐等待；一次性升级 + **每 session 维护费（持续 sink）**；维护不足 → 本局降级不掉等级。**漏雨屋顶仍不可修**。V2 期间设备不显示食材名称提示。
- **自动化率 A 七幕曲线**：0 → 20 → 40 → **0（3-3 剥离）** → 30 → 70 → 0（终章自愿）。A ≤ 70% [PLACEHOLDER]。
- **三次入队＝三条自动化线**：5-2 雷千层→练习自动化（S8）/ 5-3 顾苦→提交外送自动化（S9）/ 5-4 沈如意→结算自动化（S2）。
- **3-3 剥离**：员工离岗、设备停机、S4 置灰、工资维护停收，A 归零；玩家手上点击量翻倍，用操作系统讲背叛。3-6 顾苦那袋糖＝临时帮工回归、A 首次回升。
- **V4 自由炉**：关闭排名 / 金币 / 耐心 / 评分 / **全部自动化**，主角自己动手再烤一炉。

## 剧情触发：全部由经营进度派生（v2.0 新增，剧情未被削弱）
三插入口 G1（开门 ≤20s）/ G2（营业中单句 ≤2s **绝不弹全屏对话框**）/ G3（关门 ≤40s）、16 个高价值节拍、七幕主线、三次入队、大团圆全部保留；**触发方式改为经营派生**。

| 触发器 | 条件 | 插入口 |
|---|---|---|
| T1 经营里程碑 | 首次完成一局营业 / 累计出餐 N 单 / 当日好评率 ≥ X / 连续营业 D 天 [PLACEHOLDER] | G3 |
| T2 菜谱解锁特定点心 | 显形第 N 页（段位解锁）/ 首次学成某道 / 该道 M ≥ 阈值 | G1 / G3 |
| T3 段位与评定 | 铜 / 银 / 琉璃 / 云顶 评定通过（设定锚定） | G3 |
| T4 自动化与队伍 | 首位员工上岗 / 设备 L2 / A 达 40% / 5-2·3·4 入队（设定锚定） | G1 / G3 |
| T5 异常经营事件 | 干扰首次命中 / 连续 N 单低耐心差评 / 单局流失达阈值 | G2 |

**R5** 主线节点必须绑定至少一个经营触发器，只用可观测经营量（金币 / 页数 / M / 段位 / 好评率 / A / 在岗人数），不用隐藏计数器。
**R6** 触发器只解锁剧情不阻挡经营；主线节点在下一个 G1 / G3 播放，必触发且不可跳过，支线可跳过。
**G2 剧情必须在打烊复盘补讲（2026-11-16 用户裁定）**：G2 营业中只给 ≤2s 单句气泡、绝不弹全屏框，因此单靠气泡玩家「体会不到剧情」。凡走 G2 的节点必须在剧情卡里写全 `lines` 对白，并在**触发当天的打烊账本顶部**以对白形式完整复盘（用 `storyLog` 里当天该 id 判断）。顾苦借糖（1-4）即为首个落地：对白四句 + 「显形 ≠ 学会」收尾；营业中气泡只留悬念、不剧透结果；玩家文案不得出现编号 / 点击步数等开发术语。
**剧情回喂经营**：升段→菜单宽度；首次学成→该道进入可制作列表开始累计 M；应聘 / 入队→岗位槽与自动化线；4-7 条例松口→好评率进评定公式；5-3 收编鸽子→S9 外送单；终章→自由炉规则态。

其余咬合规则：R1 每个节点必须有「触发条件 + 场景 + 经营环节 + 产出」四件套｜R2 雷千层→练习 / 评定、顾苦→V1 干扰、沈如意→结算，入队后转自动化岗位｜R3 入队即解锁且当场可操作｜R4 章末钩子＝下一次开门提示。

## 经济
Sources：出餐收入（主）/ 评定奖励 / 外送订单 / 回头客小费 / 剧情奖励 / 练习产物售卖 [PLACEHOLDER]。
Sinks：原料采购（持续）/ **员工工资（持续）** / **设备维护费（持续）** / 雇佣与升级（一次性）/ 装扮（一次性）/ 干扰重做成本。
v1.0 的「装扮一次性 sink 导致第五章金币溢出」被结构性解决：持续 sink 挂在「在岗人数 × 设备等级」上，随进度与收入同向增长，不再外挂鸽子饲料。验证路径：25 session 收支 Monte Carlo。
**禁售**：配方 / 页数 / 熟练度 / 完美率 / 必出完美 / 跳过练习 / 自动化跳过。商业化若冲突，改商业化不改铁律。
