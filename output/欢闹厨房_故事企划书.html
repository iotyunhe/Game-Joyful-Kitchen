欢闹厨房

THE ONE HUNDRED AND ONE PAGES

一个手笨但乐观的送货少年，被一本会吐槽的旧菜谱砸中。
为了把空白页一页页填满，他开了一家甜品店——
然后被挑战、被捣乱、被背叛，最后学会了全部菜谱，
以及第 101 页上那句谁也没写出来的答案。

01 / World & Rules

核心设定

一本书、四条铁律、五阶排名——所有剧情冲突都从这套规则里长出来

《一百零一页》与书灵「糖老书」

一本封皮掉渣、会自己翻页、会打瞌睡、会打分的老菜谱，扉页写着「吃完这一本，你就是神」。书里住着个毒舌老头儿，口癖是「这炉……勉强能算个东西」。真相：他是初代「点心之神」留下的一缕念头，第 101 页正是他当年没写出来的那一页。

菜谱的四条铁律（金手指的规则与限制）

① 显形所有页面原本空白。只有店铺在「糖勺榜」升到对应段位，下一页才显出题面——菜名 + 一张料单（要什么、先下什么），外加一句莫名其妙的提示；但几克糖、火多大、等多久，一个字都不写，那些得自己一炉一炉试。
② 三重磨炼显形 ≠ 学会。每道菜必须过三关：练（反复实操攒手感）、悟（弄明白做给谁吃）、战（限时客人 / 挑战赛 / 捣乱突发下完整做出来）。
③ 不可作弊抄别人的方子、请人代做、用捷径道具 → 页面褪回空白并长出霉斑，得从头再练。喜剧惩罚，不是恐吓。
④ 越往后越挑人第 100 页的要求是：把前面所有失败过的菜，一炉一炉重做一遍。第 101 页则永不因排名显形。
正反馈仪式　一页真正学会，纸上才长出糖霜插图，还带一股刚出炉的香味。这是全作最重要的爽点载体。

糖勺榜：五阶排名对应五章

段位范围章节评定口味
铜勺街角第一章有客人愿意进门就行
银勺街区第二章技法开始被挑剔
金勺全城第三章只看配方出处与标准度 → 评定作废
琉璃勺全国第四章规则第一次为「心意」松口
云顶勺云端食榜第五章终极评定，全城围观

评审会不是反派，是制度性压力：一板一眼、只认技法不认心意。终局因主角被撬开一条缝，条例里多了一行「谁在吃」。

02 / Characters

角色设定

每个冲突角色都有可理解的动机、可辨认的性格、一条完整的弧光——以及一个入队后的岗位

麦小满主角 · 18 岁
「再来一炉就好！」
  • 面包房送货工 → 漏雨铺子「一勺糖」老板。手笨、心软、乐天，对「好吃」有野兽般的直觉。
  • 动机曲线：书上说能当神，试试呗 → 有人还愿意来吃 → 我自己还想再做一炉。
  • 致命弱点：不会拒绝人，把别人的需要排在自己前面——这正是沈如意那一刀的根。
  • 成长阶梯：手笨 → 手感 → 功夫 → 心意 → 无配方 → 放下。
糖老书引导者 · 书灵
「这炉……勉强能算个东西。」
  • 泛黄书页里浮出的皱脸，戴糖丝眼镜，说两句就打瞌睡；毒舌、嘴硬心软、护短。
  • 讲解规则、发任务、扣分、制造笑点，也埋下全作最大的伏笔。
  • 第三章被扣走前，偷偷撕下第 101 页一角塞进主角围裙。
雷千层★ 挑战者 · 谐星 · 第 5 章入队
「我不信神。我只信秤。」／「我只是路过。（第 412 天）」
  • 千层酥世家「雷记」第七代，22 岁天才。冷面、毒舌、称量到 0.1 克的强迫症。
  • 动机：表层「技术即真理」；深层是雷记被「点心之神」传说压了三代，祖父临终还念着「差一炉」。
  • 底线：绝对公平，从不使阴招，输了当场认，还替对手捡托盘。
  • 谐星标签 · 冷面反差萌：随身小秤连客人的笑声都要「记个数值」；天天说「我只是路过」却风雨无阻准点来挑刺、准点吃完两块；偷偷收藏主角每一炉失败品并按焦度编号归档，被豆豆翻出来时耳根通红。
  • 招牌翻车：1024 层被顾苦的鸽子撞翻，坚持一片片捡回重数到天黑。
  • 入队后：技法总顾问，把「雷记」改成「一勺糖·雷记分店」；依旧每天挑刺，挑完顺手把碗洗了。
顾苦★ 捣乱者 · 谐星 · 第 5 章入队
「甜是骗局！我要让这座城清醒！」（说完滑倒）
  • 自称「苦味博士」，黑斗篷是拿家里窗帘改的（下摆还留流苏），登场必先发表宣言。戏剧化、浮夸、总把自己坑了。
  • 动机：童年差两文钱被甜品店赶走 → 认定「甜是哄人的」。其实只是想让当年那个小孩，被谁递一块什么。
  • 手段：糖罐换盐、温度计调乱、胡椒烟雾弹、雇鸽子占座、伪装评论家打一星、改门牌。
  • 谐星标签 · 正经地不正经：一本《作战记录簿》把捣乱编号成「苦味作战第 07 号」，写计划、画示意图、盖自制印章，然后每次都翻车；宣言念到一半总被鸽子或豆豆打断。
  • 招牌翻车：换盐后自己先偷吃一勺，苦着脸灌三杯水；伪装评论家忘了摘「苦味博士」袖章。
  • 入队后：自封「首席试味官兼防捣乱演练总指挥」，鸽子收编为「咕咕外送队」，把自己的六种捣乱手法编成教材给新人上课，讲得极其骄傲。
沈如意★ 背叛者 · 谐星 · 第 5 章入队
「你每次都说'再来一炉就好'……可你从来没问过我累不累。」
  • 开张第一天来应聘的搭档，管账、跑堂、最会哄客人。温柔利落，笑起来像店里的灯。
  • 三层动机（已减重）：评审世家之女，家族拿弟弟的甜点学徒名额做筹码要拓印（弟弟自己跑来偷吃被豆豆抓包，镜像笑点）；她也曾是菜谱候选继承者被刷掉；以及她真的喜欢这家店，也真的委屈。
  • 背叛（轻量化但不消失）：金勺前夜紧张得手抖，拓印三页还按了三个糖霜指印、把「海盐焦糖」拓成「海盐焦…」，评审会借题发挥摘星封炉扣书 → 账本留一行「对不住」。
  • 谐星标签 · 最拙劣的伪装：出走后没走远，在街对面摆「代记账」摊，大口罩墨镜遮阳帽自以为天衣无缝——全街坊都认得她，周伯每天还特地去照顾生意，豆豆常来报告「如意姐姐又把算盘拿反了」。
  • 入队后：第五章被豆豆一句「你抽屉还留着呢」当场留下，复任掌柜；终章当着全员写下「今天不累。」，与顾苦组成「挑刺二人组」。
周伯 · 豆豆见证者 / 试吃员
  • 周伯：每天买最便宜的一块桂花糕、从不说话的老邮差。真实身份是退休的初代糖勺评审，因当年一次误判退隐。第四章被「没有配方的桂花糕」（亡妻的味道）弄哭并亮明身份，第五章投关键一票。
  • 豆豆：翻窗偷吃被抓包，顺势成了试吃员。童言暴击担当；第五章用一句「你抽屉还留着呢」把沈如意留下，是全员团圆的关键推手；终章挂上新牌子。

本作没有真正的敌人——三位冲突角色都是「还没坐到同一张桌子上」的队友。

入队写法三条约定　① 入队要当场、要热闹，伴一句笑场台词完成，仪式感靠「多摆一副碗筷」；② 旧身份不洗掉，改成新用法（继续挑刺、继续捣乱、继续算账，只换方向）；③ 终章全员同框，一个不少，不留「某某会不会回来」的悬置。
调性红线 · 大团圆修订　不出现死亡、血腥、真正的恶意。顾苦的「坏」是别扭，沈如意的「背叛」是委屈，雷千层的「狠」是较真——三人全是谐星，各有招牌翻车与反差萌。每次失败都要有喜剧落点；第五章三人全部加入主角团队，终章全员到齐，无一人离场。

03 / Narrative Spine

叙事骨架：三类冲突 × 三重磨炼

三类冲突不是并列摆设，而是成长机制的化身——每个角色专门负责把主角的一重磨炼逼出来；第五章三人全部入队后，这套关系顺势从「逼他成长」变成「陪他经营」

堂堂正正，逼出「练」 制造混乱，逼出「战」 情感断崖，逼出「悟」

05 / Chapters & Beats

章节划分与关键剧情节点

每幕包含：概要 · 情绪曲线 · 解锁内容 · 编号节点 · 爽点 · 章末钩子

00
序章 · 从天而降的一百零一页
好奇 → 挫败 → 小火苗

送货路上被旧书砸中，第一页显形「焦糖布丁 · 提示：别看钟」：菜名、料单有了，几克糖、火多大，一个字没有。

关键节点：0-1 天降旧书 → 0-2 糖老书开口「我不教笨蛋」 → 0-3 连焦三炉、厨房冒黑烟 → 0-4 蹲在炉边听见糖「噗」一声，顿悟火候要听声音不是看钟 → 0-5 第四炉成功，纸上长出糖霜插图 → 0-6 书末小字「要有人吃」，于是决定开店。

本章爽点第 1 页显形的仪式感；把「看钟」的常规思路打脸章末钩子最后一页：「第 101 页 · 留给还不知道自己为什么做点心的人」
01
第一章 · 铜勺篇《一勺糖，一间店》
热闹 ↑ → 被认可 ↑↑

关键节点：1-1 租下漏雨旧仓库、挂牌「一勺糖」 → 1-2 豆豆翻窗偷吃被抓包，反成试吃员 → 1-3 沈如意上门，一下午理平乱账 → 1-4 顾苦首次登场把糖罐换成盐，主角将错就错做出「海盐焦糖」当天爆单，顾苦踩到自己撒的糖粉滑倒 → 1-5 雷千层隔窗丢下一句「这也叫千层？」 → 1-6 周伯第一次进门，只买最便宜的桂花糕 → 1-7 铜勺通过，周伯说全章唯一一句台词「……再来一块」。

解锁接单系统 / 店铺装扮 / 糖艺入门；菜谱第 2–8 页本章爽点被捣乱反做出招牌；最沉默的客人开口要第二块章末钩子菜谱一次显出三页，糖老书：「别高兴，这才刚够你摔的。」
02
第二章 · 银勺篇《擀不薄的千层》
被碾压 ↓↓ → 平局小爆 ↑↑

关键节点：2-1 雷千层下战帖 → 2-2 初战惨败：主角擀到第五层破皮、面团糊脸，雷千层 1024 层分毫不差 → 2-3 闭关喜剧蒙太奇，面团堆成山、豆豆在里面迷路，糖老书计数「第 87 次，还是个饼」 → 2-4 顾苦胡椒烟雾弹，自己先被熏哭 → 2-5 混乱中忘了计时，面团静静松弛，顿悟层次不是叠出来的，是等出来的 → 2-6 再战技法仍输，但周伯把「好吃」那一票投给主角，平局；雷千层第一次皱眉「你这层数根本不标准……为什么好吃」 → 2-7 银勺到手，队伍排到街口。

解锁擀制 / 层次控制 / 限时订单；菜谱第 9–20 页本章爽点平局打脸（中打脸）；周伯关键一票；天才的皱眉章末钩子沈如意把一张纸叠了又叠塞进围裙口袋，灯灭了才走（拓印伏笔）
03
第三章 · 金勺篇《最甜的那天下了雨》
转折 · 全篇唯一断崖

关键节点：3-1 排队排到街口，全员备战金勺 → 3-2 评审会突然到场，出示三页菜谱拓印「配方来源不明」 → 3-3 摘星、封炉、扣书；沈如意不见，账本只留一行「对不住」 → 3-4 全城改口「那家店是靠抄的」 → 3-5 主角第一次不想开炉、摔了模具，全作唯一一次他没说「再来一炉就好」 → 3-6 顾苦破天荒没捣乱，放下一袋没动过手脚的糖就跑，跑两步滑倒、爬起来继续跑 → 3-7 豆豆和周伯把碎模具一块块粘起来，周伯第一次主动开口「明天……还开吗」 → 3-8 主角重新点炉，做了一炉谁也不卖的布丁，四个人分着吃完 → 3-9 糖老书被扣走前撕下第 101 页一角塞进围裙。

刻意设计本章不给大爽点，只给「还有人愿意来」的小暖点。张弛需要一章呼吸。章末钩子围裙口袋里那张纸角，上面什么字都没有
04
第四章 · 琉璃勺篇《没有菜谱的三十天》
稳步爬升 ↑↑ → 爆发 ↑↑↑

关键节点：4-1 评审会给最后机会：三十天后重考，但不许用那本菜谱 → 4-2 靠记忆和手感把已学每道重做一遍 → 4-3 顾苦捣乱升级却次次自坑，斗篷被烤箱勾住时主角顺手把人拽出来，两人愣三秒谁也没说话 → 4-4 被扣的原料单被人补齐，字迹工工整整，沈如意在暗处没露面 → 4-5 雷千层上门不是挑战：「我来替你作证。那些页数，是他自己一炉一炉练出来的。」 → 4-6 重考端出没有配方的桂花糕，凭周伯每天买的那块猜了三十天 → 4-7 周伯当场落泪（亡妻的味道），亮明初代评审身份，条例被撬开一条缝 → 4-8 琉璃勺、菜谱归还。

三连打脸评审会「离了书你什么都不是」／全城议论／主角自己「我以为我离不开那本书」章末钩子100 页已显形 87 页，最后 13 页写着同一句：「把摔过的，再做一遍」

第五章 · 云顶勺篇《百页齐鸣》

全员同框 · 大团圆

与玩法配置的接口建议

三段式关卡每道菜映射为练习关（无限重试、不计分）→ 剧情关（悟，触发短对话）→ 挑战关（战，限时 / 突发干扰），正好对应三重磨炼。
干扰事件池顾苦的六种捣乱手法本身就是现成事件池，按段位逐级投放，制造「战」的压力。
失去与返还第三章做一次「失去全部加成」的特殊关卡组，第四章逐道返还，正反馈最强。
回想关卡第 100 页要求重做所有失败过的菜，天然构成终局前的回顾与情感回收。
入队即解锁5-2 / 5-3 / 5-4 三人入队时分别开放对应可操作角色或店铺岗位（技法研发 / 咕咕外送 / 经营结算），让玩家当场感到「队伍变大了」。
反派喜剧资源化三人的招牌翻车可直接做成失败动画与成就彩蛋；《作战记录簿》可作收集图鉴，鸽子可作外送单位。

07 / Ending

结局、彩蛋与可延展留白

麦小满历经正面挑战（雷千层）、恶意捣乱（顾苦）、亲密背叛（沈如意）、摘星封炉、菜谱被扣、无配方重考与百页回想，掌握了《一百零一页》的全部菜谱，被云端食榜承认为「点心之神」。三位曾经的对手在第五章全部成为队友，终章全员同框——欢快大团圆，无一人离场。

终章揭示：神位从来不是学完菜谱的奖品，
而是「学完之后，还愿不愿意再做一炉」
以及「这一炉有没有人一起吃」。

片尾彩蛋 · 全员同框

新招牌豆豆踩着凳子挂上：「今日营业 · 排名不重要」。
雷记分店「一勺糖·雷记分店」是同一张桌子的延长；雷千层每天准点挑刺、挑完顺手洗碗，第 412 天还在说「我只是路过」。
咕咕外送队顾苦自封首席试味官，鸽子依旧不太听话；他开了「防捣乱演练」小课堂，讲得极其骄傲。
柜台上的账本沈如意复任掌柜，当着全员写下「今天不累。」；顾苦在旁边补一行「今天也不苦。」
没走的糖老书趴在柜台上当菜单本，继续给每一炉挑刺：「这炉……勉强能算个东西。」
靠窗老位置周伯还是最便宜的一块桂花糕，只是现在有人陪着吃。

门后那块「点心之神」的匾，被拿来垫了歪掉的面粉缸。
