01 / Assumptions & Pillars

设计前提

品类已给定；平台、目标用户、单局时长未定——先摆假设，并写清「测出来不是这样要重画哪一块」

FUN HYPOTHESIS · 一句话
好玩的核心是：把一炉「做砸了」的点心，靠反复练、忽然懂、临场稳住，变成一页会长糖霜插图的菜谱；而每翻过一页，店里就多一个人坐到同一张桌子上。

拆开只有两个动词：烤出来（操作爽点）、留下来（养成爽点）。任何系统若不服务其中一个，删掉。

五条工作假设

#假设取值若不成立，重画什么
A1平台手机为主、PC 兼容；竖屏单手可完成一次出餐若纯 PC 横屏，多桌并行可从 3 桌提到 5 桌，制作步数可加深
A2目标用户轻度休闲泛用户，无硬核时间管理经验若是硬核经营用户，「战」关限时与并发压力整体上调一档
A3单局时长[PLACEHOLDER] 8 分钟 / session（假设 5–10 分钟）波次数与 25 个 session 的切分全部作废重画；若只有 4 分钟，三重磨炼要拆到跨 session
A4商业化未定，本文不做付费与数值售卖设计确定内购后需重审「不可作弊」铁律与 sink 结构，不卖配方
A5主线体量[PLACEHOLDER] 25 session / 一周目 8–12 小时若要求 20 小时以上，靠支线扩（两文钱、看炉、失败品收藏册），不能拖长单局
这不是免责声明，是重画清单。A3 一变，第六节整张流程表的 session 列作废。

Design Pillars（4 条，用来否决需求）

P1　每一页都得自己烤出来

玩家感受：「这页是我练出来的，不是解锁出来的」。

否决：用金币直接买菜谱页 → 违反「显形 ≠ 学会」与不可作弊。

P2　失败永远有笑声兜底

玩家感受：砸了也想再来一炉，不会烦躁退出。

否决：干扰事件造成真实进度损失且无喜剧落点。

P3　队伍长度就是进度条

玩家感受：每多一个队友，柜台多一副碗筷、多一个按钮。

否决：队友只出现在剧情里、不进操作系统。

P4　排名是解锁器，不是分数墙

玩家感受：升段是为了看见下一页，不是为了被卡住。

否决：评定失败要重刷三天日常。

03 / Scenes

场景清单：9 个，分三批开放

4 个常驻 + 3 个章节限定 + 2 个入队解锁；另有两个地点刻意不建场景

常驻 · 4

序章起一直可用，是每日 session 的舞台。S4 是元场景（菜谱界面），不作物理空间。

章节限定 · 3

评定场每章末复用；小摊在 5-4 撤摊；大会场仅第五章。

入队解锁 · 2

5-2 技法台、5-3 外送站。沈如意不新增场景，直接回 S2 柜台。

04 / Mechanics

玩法类型：8 种常规 + 4 种规则态

3 核心关卡 + 3 经营 + 2 长线；每种都写清 purpose / inputs / outputs / failure state

核心关卡（对应三重磨炼，每道招牌菜必走）

ID玩法Purpose / 玩家决策Inputs → OutputsFailure state
P1制作 · 练习关（练）把手感练成肌肉记忆；决策＝何时停火、擀几层、温控到几度触屏操作 + 音频提示（糖的「噗」声）→ 手感值、失败品、焦痕无限重试、不计分、不扣资源；连焦三炉是教学不是惩罚
P2剧情关（悟）回答「做给谁吃」；决策＝一次二选一短对话 + 客人档案 → 糖霜插图解锁、关系 +1无失败；选错只换台词，不阻断（P2）
P3挑战关（战）真实压力下完整复现；决策＝并发排序、干扰应对限时订单 + V1 干扰 → 页「学成」、金币、排名积分退回练习关，不丢已学页；干扰必带喜剧落点

经营玩法（Session loop 主体）

ID玩法Purpose / 玩家决策Inputs → OutputsFailure state
P4接单经营多桌并行排序；决策＝先做哪单、先补哪种料订单波次 + 耐心值 → 金币、客流、回头客客人等走只丢本单收入，不掉段位、不扣页数（P4）
P5装扮与器具升级花钱买「看得见的变强」；决策＝先扩产能还是先换牌子金币 + 装扮件 → 客流加成、并行桌数、步数缩短纯正向；漏雨屋顶不可修（设定红线）
P6经营结算读账本做次日备料；决策＝备料量、定价收支 + 原料单 → 次日库存、账本剧情文本备料失衡 → 次日缺料，可在 S3 临时补货（花时间不花钱）

长线养成

ID玩法Purpose / 玩家决策Inputs → OutputsFailure state
P7糖勺榜段位评定把「升段＝看下一页」变成期待；决策＝带哪几道招牌菜去评已学页 + 五阶评定口味 → 段位、新页显形、新场景不达标下个 session 再评，不惩罚、不刷日常（P4）

05 / Narrative Integration

主线剧情穿插机制

剧情不另开时间线，全部挂在 session 的三个插入口上——玩家永远在「玩」

G1 · 开门钩子

位置：session 开始、接单前
形态：2–4 句对话 + 一个明确目标
时长：≤ 20 秒 [PLACEHOLDER]，可跳过
例：0-2「先说好，我不教笨蛋」、2-1 下战帖

G2 · 关中气泡

位置：制作 / 挑战关进行中
形态：单句短气泡，不暂停操作
时长：单句 ≤ 2 秒，自动滚
例：1-4 顾苦宣言、2-3「第 87 次，还是个饼」

G3 · 关门落点

位置：结算后、退出 session 前
形态：显形仪式 / 章末钩子 / 入场动画
时长：≤ 40 秒 [PLACEHOLDER]
例：0-5 糖霜插图、1-7「……再来一块」、5-2 多摆一副碗筷

铁律　G2 绝不弹全屏对话框。玩家手上正端着一炉，读字就会糊锅——这是反馈通道问题，不是叙事问题。

四条咬合规则（用来审每一个剧情节点）

#规则说明

07 / Economy & Tuning

经济系统、数值与调优表

钱从哪来、到哪去；任何 source 找不到 sink，通胀只是时间问题

图 5　Sources & Sinks：紫色与粉色两行专治「装扮买完后金币变废数字」
最大风险　装扮与器具是一次性 sink，买完即失效。S9 的持续维护费必须在 5-3 后立刻接入。判定依据：装扮购买次数有限，金币按 session 持续产出，收支缺口在装扮售罄后持续扩大；触发条件为装扮售罄，影响组件为金币池与第五章消费动机，根因是缺少持续性 sink。
商业化红线　不卖配方、不卖页数、不卖「跳过三重磨炼」的道具。「不可作弊」是剧情铁律，商业化若与之冲突，改商业化，不改铁律。
