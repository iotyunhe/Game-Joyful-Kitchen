# 《欢闹厨房》剧本文本整理与修订 v1

> 2026-11-19。整理对象：`demo/index.html` 中玩家可见的全部描述与台词。
> **保护边界：开篇（序章 9 幕）为用户亲笔定稿，全文逐字未动**；对齐序章的 4 条自检断言也保持原样。

---

## 一、诊断：AI 味与不连贯具体出在哪

| 症状 | 典型原文 | 问题 |
|---|---|---|
| 空钩子 | 麦小满「那我是不是……」 | 省略号后面没有内容，像被截断的生成结果；玩家接不住。 |
| 裁判腔 / 总结句 | 糖老书「……行，算平手。都别争了。」 | 书灵是护短嘴硬的角色，不是裁判；「都别争了」把情绪直接讲破。 |
| 对偶金句 | 「字有了，做不做得出来，还是另一回事。」 | STORY_BIBLE 已明确淘汰这类精悍对偶，但仍残留在复盘尾句。 |
| 术语直白 | 「第四页——海盐焦糖，显形了。」 | 「显形」是后台机制名，角色不该念说明书；且和复盘尾句重复讲同一件事。 |
| 引号残留 | 雷千层「条例里没有『好吃』这一项。」 | 用户定稿「台词一律不带「」」，此处用了『』漏网。 |
| 前后抢词 | 沈如意 5-4「今天不累。」 | 这句是终章 6-7 的名场面，提前在入队时用掉，终章就没了。 |
| 动作与话矛盾 | 顾苦「我带了袋糖回来。别说是我拿的。」 | 既承认带回来又否认是自己拿的，读起来像笔误，不像别扭。 |
| 旁白出戏 | 结局「主角学会了全部菜谱，店里也全自动了……」 | 「主角」是设计视角，不是故事里的声音；整句是设定复述。 |
| 开发编号漏到玩家界面 | 开门提示「3-3 剥离：人走了、炉子停了……」 | 编号属 `?dev=1` 范畴，玩家文案只说看得见的结果。 |

**不连贯的根因**：每个节点只写了一句「这句角色该说的话」，没有回应「刚刚发生了什么」。修法统一为——台词接住触发它的那件事（第一局营业、借糖爆单、铜勺、平局、扣书、回暖、无配方、条例松口、入队、自由炉），并按角色卡还其口吻。

## 二、修订对照（剧情插曲）

### 0-5 · 第 1 页长出糖霜（触发：首次完成一局营业）
| | 文本 |
|---|---|
| 原 | 糖老书：……这一炉，勉强能算个东西。／麦小满：才一页！还有一百页呢！ |
| 改 | 糖老书：……头一天，没把炉子烧了。行了。<br>麦小满：那明天再来一炉就好！后头还欠着一百页呢。 |
| 理由 | 口癖「勉强能算个东西」已在序章 0-6 说过，不在同一句重复；把「第一局营业」接上序章连焦两炉的笑点；麦小满用回口头禅。 |

### 1-4 · 顾苦把糖罐换成了盐（G2，打烊复盘）
| | 文本 |
|---|---|
| 原① | 麦小满：{客人}那单，怎么闻着有点咸？（动态改写，保留） |
| 改① | 不变——仍由 `spawnCustomer` 按实际被换的客人名字改写。 |
| 原② | 顾苦：我就借点糖……谁知道罐子里装的是盐。真不是故意的。 |
| 改② | 顾苦：我就借一勺糖……谁晓得那罐里是盐。真不是故意的！ |
| 原③ | 糖老书：糖罐盐罐一个样，你倒分得清哪个是盐。 |
| 改③ | 糖老书：糖和盐你分得清，借没借倒说不明白。 |
| 原④ | 糖老书：算了，歪打正着。第四页——海盐焦糖，显形了。 |
| 改④ | 糖老书：歪打正着。第四页翻开了，海盐焦糖。往后你多点一下，别嫌烦。 |
| 理由 | 毒舌要落在具体的事（借没借），不讲绕口令；「显形」改「翻开了」；最后一句接住本单真的多一步操作，且与复盘尾句不再重复。 |

配套：
- 营业中气泡原「我就想借点糖……　那罐糖好像不太对劲。」→ 改「借一勺糖而已……　咦，这罐怎么有点咸？」（G2 只留悬念，不剧透结果）
- 复盘尾句原「那单多走了一步，书翻到第四页——字有了，做不做得出来，还是另一回事。」→ 改「那罐盐到底还是进了方子。第四页有了字；手上那点功夫，得你自己一炉一炉练。」（拆掉对偶，保留显形 ≠ 学会）

### 2-6 · 平局

|---|---|

### 3-3 · 摘星封炉扣书
| | 文本 |
|---|---|
| 原 | 沈如意：账本我先带走，别找我。／顾苦：……我什么都没干啊。／糖老书：书让他们拿走了。今儿起，你得自己记着了。 |
| 改 | 沈如意：账本我先带走。那行字……你先别翻。对不住。<br>顾苦：……我可什么都没动啊。真的。<br>糖老书：书被他们扣下了。从今天起，方子得你自个儿记。 |

### 3-6 · 顾苦那袋糖
| | 文本 |

### 4-1 · 三十天不许用菜谱
**不动**——「字我藏起来了。」「那我怎么知道该点哪个？」「……第三格。我什么都没说。」已是全剧最顺的一拍。

| | 文本 |

### 5-234 · 三个人来帮少点几下
| | 文本 |
|---|---|
| 原 | 雷千层：我只是来校准火候。／顾苦：鸽子比我乖，真的。／沈如意：账我重新算过了。今天不累。 |

## 三、修订对照（气泡、提示与结局）

| 位置 | 原文 | 修订 |
|---|---|---|
| 顾客离场气泡 | {客人} 等走了。这单没赚着，下一位来。 | {客人} 等不及走了。这单没赚着，下一位。 |
| 开门（剥离期） | 3-3 剥离：人走了、炉子停了、书被扣了。今天所有步骤都要自己点。 | 员工没来，炉子凉着，书也被扣了。今天每一步都得自己点。 |
| 食材台通用提示 | 按配方顺序点食材；客人等得越久，赚得越少。做出完美，客人一定说好。 | 照着配方顺序点。客人等久了，钱就少了；做出完美，他一定说好。 |
| 自由炉提示 | 不算钱、不排名、也不催客人。全员都在，自己烤一炉。 | **不动**——已口语且与 6-3 呼应。 |
| 无配方提示 | 连菜谱上的字都藏了，凭手感点。糖老书说：第三格，我什么都没说。 | **不动**——口吻准确。 |
| 结局正文 | 主角学会了全部菜谱，店里也全自动了，却选择自己动手再烤一炉。故意焦一角的布丁。 | 菜谱学全了，店里也没他什么事了。他还是自己动手烤了一炉，故意焦了一角。 |
| 结局尾注 | 书灵没有散去，变成了菜单本。没有一个人离场。 | 那本旧书第二天自己翻回了柜台，继续挑刺。七个人，一个不少。 |

## 四、刻意保留（不改）

1. **序章 9 幕全文**——用户亲笔定稿，含四条规矩第二条，逐字不动。
2. **周伯「……再来一块。」**——角色卡规定的全章唯一一句。
3. **4-1 与 6-3 的全部台词**——留白节奏已经成立。
4. **1-4 第一句的动态改写机制**——仍按实际被换单的客人名字生成，避免剧情与操作不一致。
5. **所有 `?dev=1` 口径文案**——设计编号只留在开发者视图，玩家侧反而要清掉一处漏网的「3-3 剥离」。
