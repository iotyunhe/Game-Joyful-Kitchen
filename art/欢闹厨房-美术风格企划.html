01 · 风格锚点

结论：风格锚点是唯一风格来源。下面这段英文是唯一可执行版本，生成时整段复制，一个字都不改；中文八字段只用于团队评审，不进提示词。

字段定稿为什么这样定
画风2D 手绘卡通、哑光平涂 + 轻微粉质笔触休闲泛用户；粉质笔触给点心「糖粉感」，不靠写实食欲图
视角场景 / 道具 45° 俯视；角色正面四分之三同屏可见台面 + 角色上半身 + 出餐区
光照左上暖主光 + 右下暖反光，同色系阴影暖光小店；纯黑阴影会把谐星桥段压成惊悚
线宽统一 3px @1024，可可棕 #5A3B2E，外深内浅圆头浅背景下靠描边把主体抠出来，缩略图可辨的关键
质感哑光平涂、无镜面高光、无渐变光晕糖霜高光用「点」不用「反射」
比例Q 版 2.5–3 头身，头占 40%，短圆手脚、点眼 + 腮红七人同框靠头身比统一；点眼在 10% 缩略图下更可读
色彩倾向低饱和奶油暖色；冷色只给阴影 / 夜景；高饱和只给交互莓果红独占交互，玩家不会把倒计时和装饰看混
禁忌8 条，见第 04 节锚点不写禁忌，第 3 批开始必然漂

冻结文本（复制到每个提示词的第一段）

[STYLE BLOCK v1 - FROZEN]
Cozy cute 2D hand-drawn cartoon for a lighthearted dessert-shop management game. Soft matte flat coloring with a subtle chalky pastel texture, no glossy highlights, no gradients, no glow. Rounded silhouettes everywhere, zero sharp corners or spikes. Uniform 3px warm cocoa-brown outline (#5A3B2E), darker outside and lighter inside, round line caps. Chibi 2.5-3 head-tall proportions, head about 40 percent of the body, stubby round limbs, dot eyes and small blush cheeks. 45-degree top-down view for scenes and props, three-quarter front view for characters. Warm key light from the upper-left with a soft warm bounce from the lower-right; shadows stay in the same hue family, never black. Low-saturation creamy warm palette: caramel orange #E8A05C, peach pink #F3BFC0, frosting white #FFF7EA, cream apricot #F5E4C9, with muted cool tones only for shadows or night scenes; cocoa brown #5A3B2E for outlines and deepest shadows; berry red #D9534F reserved for interactive feedback only. Flat even lighting, no rim light, no lens flare, no photorealistic food photography, no realistic anatomy, no pure black lines, no text, no letters, no watermark, no signature, no recognizable brand or IP character.
版本纪律　任何修改 = 升 v2、旧版保留、并写明「推翻了哪些已产出资产」。已确认的锚点条目未经明确要求不得回退。

03 · 明度阶梯与主体 / 背景分离

结论：可爱风常用浅背景，最容易出现「缩略图糊成一片」。本作靠「浅背景 L 84–92 + 主体中调 L 40–60 + 强制深描边 L 24」把主体抠出来，转灰度仍可分。

L 90–100高光 / 糖霜
L 60–80主体亮面
L 40–60主体中间调
L 20–40主体暗部
L 84–92日间背景
L 18–32夜景背景
L 24统一描边
场景背景明度主体处理
日间（S1–S4、S6、S8、S9）奶油杏 L 89主体中调 L 40–60 + 强制 #5A3B2E 描边，形成 L 24–60 暗团，与背景差 ≥ 2 档
夜景（S5 评定场、S7 云端大会）深紫 #3E3550 L 24主体亮面抬到 L 70–85；**唯一允许**改用「外浅内深」反向描边，资产名标 _night

状态不能只靠颜色区分

倒计时　莓果红 + 沙漏形（等宽数字，不跳字）
禁用　去饱和 + 斜杠图标（第三章结算按钮少一个）
增益　焦糖橘 + 上箭头
扣书期置灰　去饱和 + 封条图形，不是只降透明度
验证方法　成品转灰度，主体与背景仍清晰可分即合格；用 art_asset_tools.py sheet 出接触表做 10% 缩略图测试。文字与底对比度 ≥ 4.5:1，点击热区 ≥ 44×44。

04 · 禁忌清单与一致性检查

结论：每条禁令都附「具体失败表现」，验收时能直接判不合格，不写「感觉不好看」。

#禁止失败表现
1纯黑描边 / 纯黑阴影谐星出糗桥段变惊悚；灰度图出现死黑块
2锐角、尖刺、尖牙、锐利道具顾苦 / 雷千层看起来像真反派，与「零锐角」锚点冲突
3镜面高光、渐变光晕、全屏泛光糖霜显形变廉价发光滤镜，L97 独占性被破坏
4写实烘焙摄影质感 / 写实解剖与 2D 手绘同屏即拼凑感
5大面积冷灰 / 冷蓝暖色小店基调丢掉，大团圆的温度没了
6同屏 > 3 种高饱和色视觉噪音，玩家分不清哪个是倒计时
7状态只靠颜色区分色觉障碍玩家读不出禁用 / 危险 / 增益
8文字、水印、签名、真实品牌、受保护 IP、在世艺术家风格抠图后文字卡在资产里；合规红线

一致性三道检查

检查做法不合格处理
同族比对七位角色排在一张接触表上统一头身比、描边色、腮红位置与辅色，只保留识别色差异
同对象状态比对主角常态 / 专注 / 失败 / 开心 四态并排统一左上主光方向与描边策略，不许一态换光向
跨类别比对角色 + S1 场景 + 菜谱 UI + 糖霜特效拼同屏UI 与特效不得比角色更抢眼；糖霜白面积 ≤ 15%
迭代收敛　版本号 _v1 → _v2，旧版改名 _deprecated 保留不删；只改指定部分，不顺手改配色或线宽；连续两轮无实质修改意见即冻结为定稿。确需改锚点时，先写明会推翻哪几批已产出资产。

参考坐标（只取结构特征）

休闲经营类构图惯例　取「45° 俯视，同屏可见台面 + 角色上半身」；不取任何具体游戏的界面与角色。
儿童绘本软描边　取「圆润剪影、暖褐描边、无锐角、粉质平涂」；不指定模仿在世画师。
中式点心铺视觉　取「暖木色、纸质招牌、糖霜白」；不取真实老字号标识。
本项目既有设定　漏雨屋顶、代记账小摊、咕咕外送队、门后的匾 —— 原创内容，直接可用。

四个实跑发现

#发现处理
1纯色底不稳定：同批两张底色是 #B09088 与 #F038B0，都不是 #FF00FF第 2 批起逐张 palette 取色再抠；统一色值批量 keyout 会整批失败
2平台水印：右下角「AI生成 / WORKBUDDY」，提示词 no watermark 无效后处理清除右下角区域（实测为主体外的纯背景，未伤主体）；每张必须目视复核
3全局 keyout 误抠：头发中间调与围裙浅色被抠掉，头顶出现大片透明缺口改为边缘连通抠图（flood fill from border, tol 35），主体内部不连通的相似色保留；重做后头发完整、焦糖橘围裙恢复
4校验口径冲突：check 要求 alpha bbox 贴合画布，但等比缩放必有留白保留刻意的 8% 安全边距，逐条说明；禁止拉伸变形；等比缩放与 8% 安全边距按规格执行

六维评审与精修项

六维评审　剪影 / 明度 / 构图 / 一致性 / 技术合规 / 可用性 全部通过 → 分档：小改（不改结构，只调明度与边缘）。缩略图测试通过，两张同族。
校验结果　check final/：命名合规、512² 为 2 的幂、RGBA 有透明通道、边缘半透明像素 0；仅剩 2 项「残留透明边」为刻意留白。
需人工精修 ①　主角围裙偏沉，需按 #E8A05C 校色；头发高光点统一到左上主光方向。
需人工精修 ②　布丁糖霜点 5 个（要求 3 个）、焦角偏花形；描边局部粗细不均需统一到 3px；AI 生成图需合规确认后方可商用。
放量结论（已定）　STYLE BLOCK v1 与 TECHNICAL v1 不升版、不改动；底色偏差由后处理链路兜住（逐张取色 + 边缘连通抠图）。直接输出透明底的方案本次不采用。第 1 批定稿前不启动第 2 批。
