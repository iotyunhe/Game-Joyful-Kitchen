# 《欢闹厨房》封面（进入页）改版提案 v1

> 交付形态：三版候选封面 + demo 实机截图。风格严格沿用已冻结的 **STYLE BLOCK v1 / 色彩板 6 色**（见 `art/欢闹厨房-美术风格提案.md`），未改任何已确认锚点。所有截图为 520×900 手机尺寸实机渲染，标注来源与版本。

## 0. 结论先行（旧版为什么必须重做）

| 维度 | 旧版 | 判断 |
|---|---|---|
| 剪影可读性 | 角色仅 112px，被文字海淹没 | 不合格 |
| 明度层级 | 标题/正文/标签几乎同一层，没有主次 | 不合格 |
| 构图与负空间 | 信息堆 9 层，5 步流程链把封面做成教程页 | 不合格 |
| 风格一致性 | 色板对，但露 `PLAYABLE SLICE` 开发副标题 | 小改可救 |
| 技术合规 | 尺寸/格式/一屏均达标 | 通过 |
| 可用性 | 主按钮被 4 个标签稀释，统治力不足 | 不合格 |

**结论：旧版属「重做」，不是「小改」。** 三版候选共同修正：① 砍掉 5 步流程链与 4 个小标签，② 主按钮放大到 17px 独占一行，③ 移除 `PLAYABLE SLICE`（已改为中文 slogan，仅 `?dev=1` 保留英文标识），④ 视觉重心收拢到「大标题 + 一张主视觉 + 一句话」。

## 2. 逐版规格与评审

### 候补 1 · 招牌立绘（推荐）
- **主视觉**：`ASSET.char`（麦小满，Q 版端布丁）+ `ASSET.s3`（店内场景）铺底、`rgba(255,247,234,.32)` 半透明压暗，角色放大到 188px。
- **为什么推荐**：信息最简、角色最突出、最贴「糖霜团子」的可爱锚点；缩略图下标题和角色都能一眼认出。参考店卡式封面的通吃结构。
- **一屏验证**：520×900 下标题 / 副标 / 场景框 / 两句文案 / 主按钮 / 次要入口全部可见，无滚动、无裁切。
- **结论**：`通过`，作为默认版。

### 候补 2 · 橱窗场景
- **主视觉**：`ASSET.s2`（店内场景）+ 角色 140px + `ASSET.pudding`（布丁）34px 菜品卡 + 「今日开张」焦糖招牌。
- **优势**：叙事感最强，一眼看懂「这是经营甜品店的游戏」；参考餐厅类游戏的商店截图。
- **注意**：场景细节多，缩到 10% 时招牌字会糊，但主标题仍可读。
- **一屏验证**：520×900 全部可见，招牌 / 角色 / 菜品卡无重叠。
- **结论**：`通过`。

### 候补 3 · 极简大字
- **主视觉**：62px 双行标题「一勺 / 糖」+ 角色 132px 角落点缀 + 勺子符号，阴影用蜜桃粉 `#F3BFC0`（淡色，避免深色阴影把「勺」误读成「句」）。
- **优势**：最像休闲爆款的极简封面，标题在信息流里最抢眼。
- **注意**：角色是点缀不是主体，若后续要做角色收集卖点，此版不合适。
- **一屏验证**：520×900 全部可见。
- **结论**：`通过`（风格定位偏极简，作为备选）。
